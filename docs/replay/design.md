# Host replay design

The approved instrument palette wins over generic dashboard styling: graphite
#181c1e, panel #232729, ink #fbf8f4, teal #2ec4a6, warning #ffb020,
danger #ff443a. System sans and local monospace fallbacks avoid network fonts
and unlicensed assets; Onest/JetBrains files are not bundled here.

The distinctive element is the full-width event strip: recorded logical time
is the organizing axis, not invented driver metrics. Left-aligned A/C above
B/D, E across the bottom. Source labels stay beside every panel; inherited
values share that panel's source. Review: keep the brief's instrument palette,
remove decorative metric cards, and make absent target evidence explicit.
Keyboard: native Tab focus, Space playback outside inputs, arrows step,
Home/End endpoints, I toggles raw-record inspection. No shell imitation.
